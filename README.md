# 🚀 AI Developer Performance Analysis

A complete exploratory data analysis (EDA) and visualization project focused on understanding the productivity, behavior, and performance patterns of AI developers.

This notebook analyzes multiple real-world inspired developer metrics such as coding hours, AI tool usage, bugs fixed, stress levels, cognitive load, sleep patterns, and task success rates to uncover valuable insights into developer efficiency and workflow optimization.

---

## 📌 Project Overview

This project explores how different factors influence the performance of AI developers.

Using Python data analysis libraries and rich visualizations, the notebook identifies relationships between:

- Coding productivity
- AI assistance usage
- Stress and cognitive load
- Sleep and work balance
- Bug fixing efficiency
- Task completion success

The notebook is designed with:

- Professional visual styling
- Interactive and attractive markdown sections
- Clean exploratory workflow
- Insight-driven analysis

---

## 📊 Dataset Features

| Feature | Description |
|---|---|
| Hours_Coding | Total coding hours |
| Lines_of_Code | Number of lines written |
| Bugs_Found | Bugs identified during development |
| Bugs_Fixed | Bugs resolved successfully |
| AI_Usage_Hours | Time spent using AI tools |
| Sleep_Hours | Daily sleep duration |
| Cognitive_Load | Mental workload level |
| Task_Success_Rate | Percentage of successful tasks |
| Coffee_Intake | Coffee consumption level |
| Stress_Level | Developer stress intensity |
| Task_Duration | Time required to complete tasks |
